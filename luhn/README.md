# Luhn Validation

## Project plan

- Validate that the input contains exactly 16 digits.
- Reject letters, spaces, punctuation, and incorrect lengths.
- Implement the Luhn checksum using a function named `checkLuhn`.
- Allow the user to validate multiple numbers.
- Test valid numbers, invalid checksums, leading zeros, and malformed inputs.

## Implementation

This program will be written in C++17 and compiled separately from the 2048 game.
